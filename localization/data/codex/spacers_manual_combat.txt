BEGIN gm_armor|装甲
ICON manual_armor
#==伤害减免==
装甲会根据被击中的装甲单元及附近单元的剩余装甲量，以及攻击的 {{穿甲力}}，降低被命中和被光束攻击造成的伤害。完好的装甲提供的伤害减免为船体装甲值的 {{85%}}}。

同一艘舰船上的装甲可能出现一处被摧毁而另一处仍然完好的情况。可通过转动舰船使更多装甲分摊伤害。
==穿甲力==
单发伤害更高的武器可对装甲造成更大损伤。{{rel:gm_damage_types|高爆}} 伤害类型最为有效，但其它高伤害能量武器也能轻易摧毁装甲。光束类武器的穿甲力取决于 DPS。
==残余护甲==
即使装甲被完全摧毁，仍能提供船体装甲值 {{5%}} 的结构伤害减免。这样，对于基础装甲值高的舰船，即使装甲被穿透，仍能抵御低单发伤害的速射武器攻击。
END

BEGIN gm_shields|护盾
ICON manual_shields
RELATED gm_damage_types|gm_flux
护盾承受的伤害会提升舰船的 {{rel:gm_flux|硬幅能}} 水平，若幅能水平达到上限，舰船将 {{rel:gm_venting|过载}}。幅能条上的小刻度表示硬幅能水平。护盾开启时，硬幅能无法耗散。

如果仅开启护盾本身，则相当于从舰船的幅能耗散中扣除一部分作为消耗。该消耗本身不会增加幅能水平，但会降低舰船耗散武器开火产生的 {{rel:gm_flux|软幅能}} 的能力。关闭护盾 {{可提升舰船的持续火力输出}}。
END

BEGIN gm_flux|幅能
ICON manual_flux
RELATED codex_weapon_harpoon
武器开火或护盾承受伤害会提升舰船的幅能水平。若幅能达到上限，舰船将无法开火，且护盾承受更多伤害会导致舰船 {{rel:gm_venting|过载}}。幅能以舰船的幅能耗散率持续耗散，舰船可 {{rel:gm_venting|主动排幅}} 以加速该过程。

==硬幅能==
{{rel:gm_shields|护盾}} 承受的伤害会提升舰船的 {{rel:gm_flux|硬幅能}} 水平。幅能条上的小刻度表示硬幅能水平。护盾开启时，硬幅能无法耗散。

常规幅能有时称为 {{软幅能}}，以区别于硬幅能。
END

BEGIN gm_venting|主动排幅与过载
ICON manual_venting
==主动排幅==
主动排幅的舰船以两倍速率消散 {{rel:gm_flux|幅能}}。在此期间，舰船无法开火或使用护盾及其他防御手段，但仍可正常移动。

主动排幅使舰船易受攻击，因此除非情况危急，通常仅在相对安全时进行。重装甲舰船通常可以以一定护甲损伤为代价主动排幅。

==过载==
过载的舰船无法开火或使用护盾及其他防御，但仍可正常移动。过载期间，幅能消散速率为正常的一半。

过载持续时间取决于护盾承受的、导致舰船超出最大幅能容量的伤害量。

过载的舰船通常会尽快撤退至安全区域，但经常成为鱼叉等终结打击类导弹齐射的目标。
END

BEGIN gm_ballistics|实弹武器
ICON manual_ballistic_weapons
实弹武器射程通常长于能量武器，且一般造成 {{rel:gm_damage_types|动能}} 或 {{rel:gm_damage_types|高爆}} 类伤害，可针对 {{rel:gm_shields|护盾}} 和 {{rel:gm_armor|护甲}} 进行特化。
END

BEGIN gm_energies|能量武器
ICON manual_energy_weapons
{{color:text|Energy}} 武器射程通常短于实弹武器，且一般造成 {{rel:gm_damage_types|能量}} 伤害，对所有防御效果均等，但无显著克制。然而部分伤害类型多样，穿甲力更高的能量武器对 {{rel:gm_armor|装甲}} 仍极为有效。

==光束武器==
光束武器射程通常极远——甚至超过 {{rel:gm_ballistics|实弹}} 武器的常规射程——但仅对 {{rel:gm_shields|护盾}} 造成 {{rel:gm_flux|软幅能}} 伤害。

尽管如此，它们仍极具价值；只是除非有数量上的压倒性优势，否则很难单独击破护盾。
END

BEGIN gm_missiles|导弹武器
ICON manual_missiles
导弹备弹量通常有限，但具有丰富多样的选择，以应对不同的战术角色。导弹槽位更多的舰船在配置上更具灵活性，可自由特化或弥补弱点。

部分导弹（如 {{rel:codex_weapon_reaper|死神鱼雷}}）使小型舰船对大型舰船构成重大威胁——在备弹耗尽之前！
